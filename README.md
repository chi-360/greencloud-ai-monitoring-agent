# GreenCloud AI Monitoring Agent

## Project Overview

GreenCloud AI Monitoring Agent is a beginner-friendly AI monitoring project inspired by OpenClaw’s skill-based architecture.

The project simulates a virtual System Administrator AI agent that monitors server health and energy efficiency within a sustainable data centre environment.

The agent analyses:
- CPU load
- server temperature
- power consumption

It automatically identifies unhealthy servers and generates AI-style optimisation recommendations.

---

## Features

- AI-style infrastructure monitoring
- Dynamic user input
- Continuous server scanning
- Server health analysis
- Colour-coded warning system
- Sustainability-focused recommendations
- Cooling optimisation suggestions
- Workload balancing suggestions

---

## Technologies Used

- Python
- Colorama
- OpenClaw-style AI skill structure
- CSV-based server simulation

---

## Example AI Recommendations

- Improve cooling efficiency
- Shift workloads to less busy virtual servers
- Reduce unnecessary power usage
- Improve energy efficiency
